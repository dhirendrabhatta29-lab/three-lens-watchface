# Credits

## Made by

- **Claude** (Claude Sonnet 5.5, by [Anthropic](https://www.anthropic.com)) designed and wrote this watch face: the Watch Face
  Format XML, the generator script, the animation expressions, the Material 3 color system, the always-on styles, the build
  workflows and this documentation.
- **The repository owner** directed the project, chose the look, sketched the *Wheel dial*, *Minutes pie* and *Activity rings* always-on designs, tested the builds on a real Galaxy Watch 7 and reported what
  worked and what did not. Claude could not run the face on a watch, so the feedback made the result.

## Based on

- **noma-Launcher** by [amalsnair535](https://github.com/amalsnair535/noma-Launcher) (MIT). The rotating wheel dial, the numeral
  rings and the pill-shaped reading window are adapted from its `RotatingWheelsClock`.
- **Concentric** watch face by Google, which inspired the launcher's wheel design.
- **Pixel Watch** faces, which inspired the always-on styles (design inspiration only; no assets are used).

## Design system and tools

- **Material Design 3** by Google: color roles, tonal palettes, shape scale and type roles.
  Tonal palettes are generated with [materialyoucolor](https://pypi.org/project/materialyoucolor/), a Python port of
  Google's Material Color Utilities (Apache-2.0).
- **Watch Face Format** documentation and runtime by Google / Wear OS.
- **Pillow** and **fontTools** were used to render the preview images and subset the font.
